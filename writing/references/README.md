# 范文与写作方法

这里收录 27 项既有范文的来源索引和自写阅读笔记。**参考模板指真实文章，不指需要填空的标题框架。** 可以借用一篇文章组织推导的办法、另一篇解释代码的办法，也可以判断现有范文都不合适。

先说清这次文章希望读者理解什么、带走什么，再选择值得打开的原文。以下只是入口，不是题材路由表：

- 想把一个概念讲明白：Rust Ownership、D2L 反向传播；需要直觉与模型来回对应时，可读 Momentum。
- 想让读者亲自做出来：Annotated Transformer、asyncio Crawler、Triton、Mathematics in Lean。
- 想理解方案为何成立或代价在哪：PPO、DPO、NLL RFC、nginx、Transformer Circuits。
- 想评价证据或实现差异：RL That Matters、37 PPO Details；不要让范文代替本次论点的研究证据。
- 想形成自己的判断：Bitter Lesson、Thurston；判断需要来自可核对的材料，不需要模仿作者的语气和履历。
- 想查找、复习或继续深入：Policy Gradient Notes、Matrix Calculus、Beej、Convex Optimization。

## 原文如何访问

原文合集 `Seagull_Writing_Exemplars_27.zip` 保存在用户私有资料中；有 27 项作品、33 个原文文件，含译文与多种格式，不能把文件数当作品数。公开仓库不保存 ZIP、原文全文、网页快照或未经授权的图。每项链接指向原作者、官方项目或论文入口。

有私有资料权限的执行环境可以由用户提供合集或把它放到仓库之外，再按原文文件阅读；没有该权限的 Codex 不会因为读到了本文就自动拥有合集。此时可访问公开原站，或明确报告无法访问并请用户提供相关篇目。不能用模型记忆假装完成阅读。公开文档不依赖某台电脑的绝对路径、私有 Library 标识或签名下载地址。

归档于 2026-11-15，本轮阅读于 2026-11-18。HTML 不是完整离线镜像，图片、公式和交互可能需联网；本轮没有运行下载代码或网页脚本。PDF 文本抽取也可能丢失公式与版面。确需分析视觉或交互时，应另行查看原页面并记录检查结果。

## 这批材料尚不能证明什么

这是以技术写作为主的起始参考库，不是完整文体库。英文材料占多数，中文部分包含译作，不能据此宣布形成了适合作者的中文文风。个人学习日志、真实失败记录、中文原创论文批评等仍不足。阅读笔记不代表原文技术结论已逐项复核，更不代表模型写作质量已通过人工验收。

原站可下载不等于可公开转载；代码许可证也未必覆盖文字、图片或外引素材。此目录只发布自写分析和来源链接。若以后确需加入原文，逐项检查授权、署名与第三方素材范围。

版本提醒：vLLM 的 Paged Attention 原件明确标为历史实现文档，不是当前内核代码的依据；Rust RFC、nginx 与 asyncio 范文也需要按其年代理解。
