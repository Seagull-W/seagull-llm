## 人工决定质量

分批交付可读初稿。请审阅者判断：这是不是想读的文章？哪段真正讲明白、哪段仍不懂？保留、小改还是重写，理由是什么？反馈指向具体版本和段落，不强求打分。

事实、引用、数学和命令另做技术核查。机器核查与人工评价分别记录；没有人工反馈就保持待审阅。人类认为不好读的文章不能凭自动分数转为通过。

失败先定位材料、路由、论证或表达问题，再改对应层。单次失败不自动上升为永久禁词或固定章节。改共享规则后，重跑受影响题目及一道其他体裁的回归题，再用留出题评议。
