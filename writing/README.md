# 写作总则与类型路由

本文是正文写作的入口。先确定交付对象与读者，再选择一份体例。
体例决定语气和组织，正文格式、视觉与发布分别由专门文件维护。

## 文档按职责分层

| 层 | 文件 | 管什么 | 不管什么 |
| --- | --- | --- | --- |
| L0 | [AGENTS.md](../AGENTS.md) | 任务分流、边界、必做验证 | 语气、结构、格式 |
| L1 | `writing/*.md`（总则与三份体例） | 写给谁、怎么组织、语气、引用、篇幅 | HTML 结构、命令、样式 |
| L2 | [HTML_FORMATS.md](../HTML_FORMATS.md) | 正文落到什么文件、公式与图怎么写 | 语气、文章结构 |
| L3 | [VISUAL_STYLES.md](../VISUAL_STYLES.md) | 页面外观、配色、动效 | 内容与结构 |
| L4 | [publishing.md](publishing.md) | 入口登记、标签、草稿、验证命令、推送 | 文风 |

`writing/publishing.md` 虽与体例同目录，职责属于 L4。
每层只回答自己那类问题，低层不得重述高层规则；需要关联时给出指针。
格式或视觉文档中的栏目示例只演示其本层职责。

## 三类正文的判定

| 类型 | 读者 | 体例文件 | 当前栏目 |
| --- | --- | --- | --- |
| 科普、教程 | 零基础读者 | [llm-book.md](llm-book.md) | `docs/llm-book/`（已撤下公开站） |
| 知识笔记 | 自己与同行，查用 | [note.md](note.md) | `cs336`、`rl-book`、`westlake-rl`、`rust-notes`、`linux-notes`、`cuda-notes`、`vllm-notes`、`papers`，以及新建的数学类栏目 |
| 调研 | 要据此判断或复述的人 | [research.md](research.md) | `docs/research/` |

按正文用途选择：

- 给人一口气读懂的入门书，使用科普体例。
- 日后回查的技术条目，使用笔记体例。
- 一段时间内发生了什么、该信哪个，使用调研体例。

论文精读、课程讲义、数学笔记都属笔记体例，统一使用 `note.md`。
工具与系统知识按技术条目处理；标题中出现“介绍”或“学习”不改变判定。
领域结构的综合汇报也可采用调研体例，具体交付目的由 `research.md` 区分。

新建栏目先确定上述类型，再沿用对应体例。
现有栏目改写时，以本次交付目的核对类型；若目的保持不变，沿用原类型。
混合材料选一个主交付，补充材料作为相应章节或附录组织。
栏目示例中的语气只适用于其所属类型。

## 跨类硬规则

以下六项适用于三类正文，证据和准确性要求共同执行。

1. **论断有出处。** 教材、原始论文和官方文档优先；二手博客不作唯一依据。
   结果式规则给出直接出处，引用放在所支持的论断附近。
2. **符号有说明。** 每个公式后必须有一句符号说明；自定义记号首次出现必须定义。
   记号的具体约定由对应体例组织，渲染写法按 L2。
3. **数字有条件。** 写清任务、样本、版本和评测方式。
   性能断言随成立条件一起表述，不能省成无条件的结论。
4. **记录可核实。** 不编造数据、引用、命令或实验结果。
   核实不了的内容标注“未核实”，保留影响解释的缺口。
5. **成稿必读。** 每份成稿过一遍 [affirmative-first-writing](../.agents/skills/affirmative-first-writing/SKILL.md)。
   按该技能完成表达修订，并保留必要的事实更正、证据限制与安全提示。
6. **正文格式统一。** 一律按 [HTML_FORMATS.md](../HTML_FORMATS.md) 落地，不自行发明结构。
   文件对、公式、图片、图注与组件使用同一份格式依据。

## 冲突按职责仲裁

语气与组织以 L1 为准；文件结构、公式写法、图注以 L2 为准；
外观以 L3 为准；流程与命令以 L4 为准。
两份文件说法冲突时，按分层表定位，不靠新旧。

处理冲突时先确定争议属于哪类问题，再回到负责该问题的文件。
其他层中重复的规定改为指针；独有细节迁入负责文件后保留。
同一层内，总则管跨类硬约束，选定体例管本类的组织与表达。
用户对当前任务明确给出的范围、交付目的与限制优先执行。

例如，知识笔记的开头与人称由 `note.md` 决定。
栏目 HTML 样例中的导语文字不构成笔记的组织要求。
同一篇文章的公式标记由 L2 决定，配色由 L3 决定。
新增文章需要登记哪些入口、运行哪些检查，由 L4 决定。
