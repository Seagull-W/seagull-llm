# Hermes → Codex 交接模板

> **核心原则：原文透传，零二次改写。**
> Hermes 只负责把用户原话、材料和执行边界完整交给 Codex；**禁止**总结改写用户意图、预设提纲/比较轴、或额外叠加写作硬约束。

```markdown
## 用户原话（逐字保留，禁止改写）
> 在此原样粘贴用户消息；修订轮追加用户最新反馈原话。

## 附带材料与链接
- 原文链接 / PDF / 截图转写路径（无则填“无，由执行者自行检索”）
- 若为修订轮：上一版初稿的绝对路径

## 本轮执行与交付
- 遵循技能：`.agents/skills/paper-research/SKILL.md`（其他任务按 `AGENTS.md` 选择入口）
- 本轮阶段：初稿 / 按用户反馈修订 / 仅给选材清单
- 交付格式与路径：独立 HTML（默认），保存至 `<绝对路径，例如 .research/handoffs/<task>/draft-v1.html>`
- 权限边界：允许联网检索（是/否）；允许发布上站（否，初稿完成后停下等待反馈）
```
