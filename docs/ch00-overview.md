# 第 0 章 大模型全景：在你打开下一页之前

## 本章导引

> 在你翻开第一章之前，先花五分钟站到高处看一眼全景。这一章不打开任何黑盒、不出现任何公式，只回答四个问题：大模型是什么、它能做什么、它大概怎么工作、这本书该怎么读。读完这一章，你会拥有一张"地图"——后续每一章，都是地图上一个被放大的站点。

## 0.1 你已经被它包围了

你可能没意识到，但大模型已经悄悄走进你的日常。

早上你打开手机，搜索引擎的摘要直接把答案摆在链接前面；午休时你让豆包帮你润色一段周报；下午查一份英文文献，DeepSeek 或 Kimi 几秒钟给出中文要点；晚上刷到的短视频，字幕和推荐背后也有它的影子。更不用说 ChatGPT——那个你随口问一句、它就洋洋洒洒回答一整屏的工具。

你不需要专门去"使用大模型"，因为它们已经嵌在你每天触手可及的产品里。问题不再是"要不要了解它"，而是"你愿意被它影响多久，才回头看一眼它到底是什么"。

## 0.2 一句话定义大模型

先把所有术语推开，用一句话说清楚：

> **大模型，就是一个读过海量文本、能根据上文猜出下一个词、从而生成连贯回答的程序。**

这句话里每个词都值得记住，但此刻你只需要抓住三个关键词：**读过**（它从人类写下的巨量文字里学到了规律）、**猜**（它本质在预测，不是在"查"）、**生成**（它的输出是现编的，不是从某本书里复制粘贴的）。

至于"大"字有多大——大到训练时"读"过的材料，相当于几十万本长篇小说。这个规模感，我们在第一章会给你一个更直观的换算。

## 0.3 黑盒的外壳：输入文字、输出文字、一个字一个字来

现在先不打开黑盒内部，只看它的"外壳"长什么样。你和大模型打交道，本质上只发生三件事：

1. **你输入文字**：一个问题、一段要求、一篇文章，都行。
2. **它输出文字**：一段回答、一段翻译、一段代码。
3. **而且是一个字、一个字地蹦出来**——不是想好了整段才一次性显示。

第三点尤其重要。你在屏幕上看到回答"一个字一个字蹦出来"，不是产品为了好看加的动画，而是大模型真正的工作方式：它每一步只预测下一个词，接上去，再把更长的文字重新看一遍，预测下一个——如此循环，直到回答结束。

这个"外壳"就是本书第一层要帮你逐步拆开的东西。此刻你只需要记住它的样子：**文字进、文字出、一次一个字**。至于里面那台机器怎么运转，留给后面的章节。

## 0.4 它改变了什么

为什么这本书值得你花时间？因为大模型改变的不只是一种工具，而是"获取知识和完成任务"的方式本身。

- **以前**：你要会检索，在海量结果里自己筛选、综合；要会外语，才能读懂外文文献；要懂编程，才能让计算机替你干活。
- **现在**：你用自然语言提需求，它替你检索、综合、翻译，甚至写好可运行的代码。

这并不意味着你被替代了——恰恰相反，判断它给的答案对不对、把它用在该用的地方，比以往更需要你的专业素养。它是一把很强的新工具，但方向盘仍在你手里。这本书的目的，就是帮你握稳这个方向盘：既知道它能帮你到哪，也知道它会在哪里把你带偏。

## 0.5 这本书的三层结构与阅读建议

全书分三层，由浅入深：

- **第一层 · 建立直觉**（第 1–7 章）：大模型到底在做什么、怎么做到的。从一次对话说起，经过 Token、词嵌入、Transformer、注意力，到训练和"涌现"。读完这层，黑盒就不再是黑盒。
- **第二层 · 理解边界**（第 8–12 章）：它擅长什么、做不好什么、为什么会"一本正经地胡说八道"，以及怎样更好地向它提问、怎样评估一个模型的好坏。
- **第三层 · 走向实践**（第 13–18 章）：如果你想把大模型用到自己的专业领域或产品里，这里有生态概览、模型选型、RAG、微调、部署和成本的入门地图。

**阅读建议**：如果你是零基础，请按顺序读第一层——它是后续一切的地基。第二层可以挑你最关心的章节读。第三层面向有实践需求的读者，用到时再查也不迟。每一章都自成一体，但它们共同拼成的，是本章末尾那张全景地图。

## 0.6 你不需要先懂数学

最后，把最重要的一句话放在这里：**你不需要先懂数学，才能读懂这本书。**

凡是出现公式的地方，我们都先用大白话把直觉讲清楚，公式只是给愿意看精确版本的读者准备的"加餐"，跳过它，你一样能抓住核心。本书甚至允许你跳过整章的"深入·可选"小节——它们是为想走得更远的人准备的，不是通关的门票。

大模型是这个时代最重要的技术之一。别让一个符号、一个术语，挡住你了解它的路。
