A1 · 从 RoPE 到 Transformer 块 ​

从位置编号、旋转与注意力分数，走到 RMSNorm、SwiGLU 和残差堆叠：逐步核对形状、手算数值、初始化与测试边界。

记 B 为批量，T 为序列长，d 为模型宽度，H 为头数，d_k=d/H，h 为前馈宽度，V 为词表大小。数值均为手算示例。

位置不是词元编号 ​

词表 ID 决定查哪行嵌入，位置决定旋转角度。ID=[42,7,42] 的位置为 [0,1,2]，同一 ID 可有不同位置。RoPE.py · forward 的 docstring 特意说，token_positions 与 token-word 映射没有必然联系。

因果掩码（causal mask）只挡未来，不直接给出“隔几步”；网络仍可能从可见范围获得顺序线索。

绝对正弦位置编码（sinusoidal positional encoding）先把位置向量加到嵌入上，再投影 Q、K。正弦支持位移关系，但点积里的内容与位置交叉项并不只依赖位置差。旋转位置编码（Rotary Position Embedding，RoPE）则直接旋转 Q、K；固定它们的内容后，点积中的位置因素严格只依赖 n−m。

RoPE 为什么只跟位置差有关 ​

用二维旋转看两个位置怎样在点积里相减。

转置交换两个非对角元素；余弦是偶函数，cos(−α)=cos α，正弦是奇函数，sin(−α)=−sin α，所以新矩阵恰好反向旋转。由角度加法公式，R(a)R(b)=R(a+b)，故 R(α)ᵀR(α)=I，旋转保长度。

手算 q=k=(1,0)、ω=1。位置 3 与 2 的点积为 cos 3 cos 2+sin 3 sin 2=cos(−1)≈0.540302；整体移到 8 与 7，仍是 cos(−1)。这里必须是同一对 q、k 内容不变。上游表示改变时不保证成立；多维情形累加各对贡献。

按位置生成角度表 ​

角度表预算位置×频率，前向按位置取行。摘自 RoPE.py · RotaryPositionalEmbedding.__init__：

assert d_k%2==0
k=torch.arange(0,d_k/2,1)
freq=theta**(-2*k/d_k)
i=torch.arange(0,max_seq_len,1)
angles=i.unsqueeze(1)*freq.unsqueeze(0)

令 L=max_seq_len。k 和 freq 都是 [d_k/2]，i 是 [L]；两个 unsqueeze 分别得到 [L,1]、[1,d_k/2]，广播相乘得到 [L,d_k/2]。偶数断言保证每个坐标都有配对伙伴。d_k=4、θ=10000 时，k=[0,1]，freq=[1,0.01]，第 3 行角度为 [3,0.03] 弧度。

相邻频率之比恒为 θ^(−2/d_k)，所以是几何级数。波长 λ_k=2π/freq_k，范围从 2π 到 2π·θ^((d_k−2)/d_k)，有限维度的末项并未达到 2πθ。10000 是沿用原 Transformer 正弦编码的尺度选择，不是推导强制的常数，也不是上下文长度上限。

源码用 register_buffer("sin",sinTensor,persistent=True)，余弦同样注册。它们进入 state_dict，跟随 .to(device)；这里常量不求梯度，也不进优化器的 parameters()。buffer 本身并不强制禁止梯度。

L 是查表硬上限：合法位置为 0…L−1，索引 L 就越界，表不会自动扩展；负索引会从末尾取行，也应拒绝。

把一对坐标转过去 ​

把旋转翻译成张量操作时，先核对坐标怎样配对。

RoPE.py · forward：拆对、乘加、拼回的原实现
sin_tensor=self.sin[token_positions]
cos_tensor=self.cos[token_positions]
x_reshaped=x.contiguous().view(*x.shape[:-1],-1,2)
x1=x_reshaped[...,0]
x2=x_reshaped[...,1]
rotated_x1 = x1 *  cos_tensor- x2 * sin_tensor
rotated_x2 = x2 *  cos_tensor+ x1 * sin_tensor
return torch.stack([rotated_x1,rotated_x2],-1).view_as(x)

末维拆成 [d_k/2,2]，x1、x2 分别取各对第一、第二分量。例如 (1,0,1,0) 拆成 (1,1) 与 (0,0)。两行乘加就是旋转；stack 交错拼回，view_as 恢复形状。前面可能刚做 transpose；contiguous 保证 view 可用，准确说 view 拒绝的是不兼容的步幅，并非所有非连续张量。

在位置 3，手算结果是 (cos 3,sin 3,cos 0.03,sin 0.03)≈(−0.989992,0.141120,0.999550,0.029996)。位置 0 的 sin 为 0、cos 为 1，应该逐项原样返回，这是最省事的自检。

还有前后半拆分的 GPT-NeoX 风格：四维时配 (x₀,x₂)、(x₁,x₃)，本实现则配 (x₀,x₁)、(x₂,x₃)。同一输入会给出不同结果。两者都保长度，但权重布局必须匹配；test_rope 的固定快照只接受其对应约定，不能“看起来在转”就算对。

缩放点积注意力 ​

旋转后的 Q、K 打分，经 softmax 变成权重，再加权 V。Q、K 为 […,T_q,d_k]、[…,T_k,d_k]，分数为 […,T_q,T_k]；乘 […,T_k,d_v] 的 V 得 […,T_q,d_v]。

假设 q_i、k_i 独立、零均值、单位方差，各维乘积不相关，则每项量级约 1，Var(q_i k_i)=1，Var(Σq_i k_i)=d_k。d_k=64 时，点积标准差约 8，缩放后约 1。训练后的表示未必严格满足这些假设。过大的分数差会让 softmax 接近单点选择，导数 p_i(δ_ij−p_j) 接近 0。

score=torch.matmul(Q,K.transpose(-2,-1))
score=score/torch.sqrt(torch.tensor(d_k,dtype=Q.dtype,device=Q.device))
if mask is not None:
    score=score.masked_fill_(~mask,float('-inf'))
attn_weights=softmax(score,dim=-1)
return attn_weights@V

Scaled_Dot_Product_Attention.py · scaled_dot_product_attention 约定 True=允许，因此对 ~mask 填 −∞。有合法键时 exp(−∞)=0；有限负数只是近似，依赖精度与分数尺度。masked_fill_ 是原地写：本路径未复用旧 score；新增分支时须确认 autograd 不需要其旧值，否则可能触发版本检查。

softmax.py · softmax 用 x.max(dim=dim,keepdim=True).values 取每行最大值，再算 exp(x−max)/sum(exp(x−max))。减同一有限数保持比例、避免上溢：[1000,1001] 化为 [−1,0]，概率约 [0.268941,0.731059]。带 dim 的 max 返回 values 与 indices，keepdim 保留广播轴。

整行全屏蔽会产生 NaN：最大值也是 −∞，相减出现 −∞−(−∞)。因果掩码保留对角线，不会触发；padding 掩码可能造成全屏蔽行，须另定义输出策略。

多头：拆、转、合 ​

沿 Causal_Multi_Head_Self_Attention.py · forward 接起注意力路径；d=8、H=2 时，每头 d_k=4。

步骤输入 → 输出操作与约束
Q、K、V 投影[B,T,d] → 各 [B,T,d]三个独立的 d×d 矩阵，无偏置
拆头[B,T,d] → [B,T,H,d_k] → [B,H,T,d_k]view 拆末轴，transpose 交换 T、H
位置广播、旋转[B,T] → [B,1,T] → 查表 [B,1,T,d_k/2]在 H 轴广播；Q、K 形状不变，V 原样保留
分数与掩码QKᵀ → [B,H,T,T]；mask 为 [T,T]掩码广播到批次与头；softmax 后乘 V
合头[B,H,T,d_k] → [B,T,H,d_k] → [B,T,d]transpose → contiguous → view
输出投影[B,T,d] → [B,T,d]d×d 矩阵混合各头输出

拆头调用 view(*Q.shape[:-1],H,d_k).transpose(-2,-3)；合头是 transpose(-3,-2).contiguous().view(...)。

transpose(−2,−3) 把 T 和 H 对调。token_positions.unsqueeze_(-2) 却还会修改调用方传入的张量：[B,T] 变成 [B,1,T]，重复传递可能继续增轴。可改用非原地 unsqueeze。位置 [1,T] 也能跨批次广播。

源码用 triu(...,diagonal=1) 标出严格上三角，再取反，得到包含对角线的下三角允许矩阵。

合头先换回 T、H，contiguous 整理内存，view 合并 H 与 d_k，拼起同一位置的各头。省掉 contiguous，view 通常会报错；改用 reshape 则可能隐式拷贝。四个投影共 4d² 个参数，与头数无关。

RMSNorm：平方之前先升精度 ​

注意力入口的均方根归一化（Root Mean Square Normalization，RMSNorm）沿末维调尺度，保持 [B,T,d]。

层归一化（LayerNorm）减均值、用中心化方差；RMSNorm 不减均值，少一次归约（reduce）。ε=1e−5 加在平方均值之后、平方根里面，不是 √mean(x²)+ε。

in_dtype = x.dtype
x_f32 = x.to(torch.float32)
x_square=x_f32**2
x_mean=x_square.mean(dim=-1,keepdim=True)
rms=torch.sqrt(x_mean+self.eps)
x_normed=x_f32/rms
return x_normed.to(in_dtype)*self.weight

RMSnorm.py · forward 在平方前转 fp32，因为 fp16 最大有限数是 65504，而 256²=65536，单个分量到 256 附近就可能溢出。增益 weight 为 [d]，全 1 初始化不额外缩放坐标。

这里先降精度再乘增益，参考实现先乘再降，fp16 舍入不同；weight 为 fp32 时还会提升精度。

SwiGLU 的宽度从哪来 ​

门控多出一块矩阵，前馈隐藏宽度必须按参数预算来算。SwiGLU 是使用 SiLU 的门控线性单元（Swish Gated Linear Unit）；SiLU 是 Sigmoid Linear Unit，SiLU(t)=t·sigmoid(t)。

x_w1=self.w1.forward(x)
x_w3=self.w3.forward(x)
return self.w2.forward(F.silu(x_w1)*x_w3)

SwiGLU.py · forward 的 w1、w3 都把 [B,T,d] 变成 [B,T,h]；SiLU 保持形状，再与另一支逐元素相乘，w2 映回 [B,T,d]。SiLU 正大值近似线性，负大值趋零但可为负；门不只是 0/1 开关。

docstring 的参数账是：普通宽度 4d 的两层前馈有 d·4d+4d·d=8d²；本实现三块无偏置矩阵分别为 [d,h]、[h,d]、[d,h]，共 3dh。令 3dh=8d²，得 h=8d/3。d=768、h=2048 时参数为 4,718,592；h=3072 则有 7,077,888，多 50%，同时改变了门控与参数量。

d_ff 由调用者给定，代码不会按 8d/3 自动反算。这一点在 A2 的模型表里能看得很清楚：small 仍然写 d_ff=3072，正好是 4d，把它直接当作三块矩阵的隐藏宽度，于是 SwiGLU 落成 3·4d²=12d²，比参数对齐的 8d² 多出 50%。按这个约定重算参数量，small 得 7,680,000（嵌入）+12×9,438,720（每块含 4d² 注意力、3d·d_ff 前馈与两个 RMSNorm）+7,680,000（输出投影）+768（末层归一化）=128,625,408，与 `benchmark.py` 打印的 128,625,408 逐位相同；换成 h=2048 就只有 100,313,856。所以读到论文里的 h=8d/3 时，先确认那个实现对 d_ff 的定义，别把两种约定下的 d_ff 直接对比。

块、残差与堆叠 ​

两个分支必须返回 [B,T,d] 才能接回残差。transformer_block.py · forward：

z=x+self.MHA(self.RMSNorm1(x), token_positions)
output=z+self.SwiGLU(self.RMSNorm2(z))

这是前置归一化（Pre-Norm）。y=x+F(Norm(x)) 的雅可比为 I+J_F·J_Norm；深层反传连乘时有恒等路径，梯度可绕过分支的归一化与非线性。这不保证梯度永不消失或爆炸。后置归一化（Post-Norm）为 Norm(x+F(x))，雅可比是 J_Norm·(I+J_F)，主路径也经过归一化。

run_transformer_lm.py · TransformerLM.forward 先把整数 [B,T] 查成 [B,T,d]；ModuleList 注册各层，for layer in self.layers: x = layer(x) 才实际逐层执行。再经 Final_RMS、lm_head 得 [B,T,V] 的 logits（未归一化分数）。

B=4、T=512、V=10000、fp32 时，仅 logits 就占 4×512×10000×4=81,920,000 字节，即 81.92 MB 或 78.125 MiB，不含梯度与其他状态。源码注释说 lm_head 常与 embedding 共用参数，但此处独立创建两个 Parameter，没有权重绑定；嵌入为 [V,d]、本 Linear 为 [d,V]，真要共享还须处理转置关系。

初始化与那些容易忽略的默认值 ​

初始化的设置要同时看三件事：权重的尺度、存储方向，以及参数有没有被注册进模块。

linear_and_embedding_module.py · Linear.__init__ 使用 [in,out] 权重，前向为 x@weight；注意它不是常见的 [out,in]。σ=√(2/(in+out))，截断范围 ±3σ。σ 是截断前标准差，截断后方差略小。embedding 则按 N(0,1) 截断到 [−3,3]。

注释摘录了 mean is more than 2 std from [a, b] 警告，但mean=0、std=1、a=−3、b=3 不会触发它。PyTorch 初始化源码判断的是 mean<a−2std 或 mean>b+2std，而非“截断边界离均值超过 2σ”。代入得 0<−5 或 0>5，均为假；无需改成 ±2。真有警告须查实际传参。

nn.Parameter 赋给模块属性后默认 requires_grad=True，注册到 parameters() 和 state_dict；普通 Tensor 不自动注册。embedding.forward 的 self.weight[token_ids] 是花式索引；反向按行 scatter-add（散射累加）。例如 ID=[2,2]，两处上游梯度分别为 a、b，weight 第 2 行就收到 a+b，整数 ID 本身没有梯度。

怎么验：先对坐标，再对整块 ​

从局部查到组合，才能定位错误。以下为验证方法，本次未运行作业测试。

  1. 位置 0 恒等：检查旋转结果逐项等于输入，
  2. 固定同一对 q、k，把 m、n 同时加 5，检查点积不变；位置须在表内。
  3. 取 d_k=4、θ=10000、位置 3、x=(1,0,1,0)，逐项对照 (−0.989992,0.141120,0.999550,0.029996)，锁定频率、配对和符号。

前两项还不够：错误配对也能保平移点积。“长度不变”更弱，频率分错坐标仍能通过。tests/test_model.py · test_rope 使用 numpy_snapshot.assert_match(output, atol=1e-5)，约束具体坐标约定。

test_multihead_self_attention_with_rope 若失败，沿“拆头 → 位置广播 → 掩码 → 合头”排查：T/H 是否换对，位置是否重复 unsqueeze，对角线是否保留，合并的是不是同一位置的所有头。容差为 1e−5。

test_scaled_dot_product_attention 检查基础 Q/K/V/mask 输出；专门将张量改为四个轴、2 个头的是 test_4d_scaled_dot_product_attention，它拆出 head=2，Q/K/V 与掩码均为四维，容差 1e−5。“四维”不是 d_k=4；共享 [T,T] 掩码的广播还须另验。

随后验证 RMSNorm、SwiGLU、块和整模型。快照加载给定权重，不覆盖初始化、低精度溢出和全屏蔽行。

本篇要点 ​

位置生成角度，旋转把位置差引入 Q/K 打分；缩放、掩码与 softmax 得到加权 V 的系数，合头投影后接回残差。RMSNorm 控制尺度，SwiGLU 扩宽并门控，堆叠后输出 logits。每步都要对上坐标、形状和数值。

原注释系统化了什么
RoPE.py：位置“和token-word映射表没有必然联系”区分词表 ID 与位置；固定内容才可讨论平移不变。
RoPE.py：“注册到buffer中，且存在state_dict中”分开保存、设备迁移、梯度与优化器参数注册。
Causal_Multi_Head_Self_Attention.py：“torch.triu, when diagonal=1”严格上三角取反，True=允许；对角线避免因果行全屏蔽。
linear_and_embedding_module.py：“nn.Parameter与普通tensor的区别”及 init 警告注册与默认梯度是两回事；按真实触发条件排除 ±3σ 的误解。
softmax.py：“tensor.max()返回values and indices”限定带 dim 的调用，解释 values、keepdim 及全 −∞ 行。
