第 5 讲 · GPU 执行与显存访问 ​

从线程块和显存层次讲到分块矩阵乘法，解释为什么数据复用能缩短运行时间。

线程、线程块与 SM ​

矩阵有许多可以同时计算的输出元素。CUDA 程序把工作分给线程，再把线程组成线程块。一个线程块由一个流式多处理器（SM）执行，块内的线程可以使用共享内存并同步。NVIDIA GPU 把线程按 32 个一组的 warp 调度；同一 warp 内的线程若走不同分支，各分支可能要依次执行。

一次计算中的数据搬运 ​

输入通常放在全局显存。线程从显存取数，在寄存器中计算，最后把结果写回。如果许多线程读取相邻地址，硬件有机会合并内存访问。如果一个块里的线程反复需要同一份数据，可以先把它放进共享内存。寄存器和共享内存的容量有限，留在片上的数据需要分批安排。

分块矩阵乘法 ​

设 C = AB。计算 C 的一个小块时，先取 A 的一块和 B 的一块。块内多个输出元素复用这些输入，各自累加点积的部分和。沿公共维移到下一对输入块，直到点积算完，最后把输出块写回显存。分块的好处来自输入复用；块取得太大，又可能放不下。

这正好对应第 2 讲的计算强度。乘加次数近似相同，分块减少了从显存重复取数的次数，每搬一个字节能完成更多运算。GPU 的 Tensor Core 和 TPU 的矩阵单元都擅长规则的矩阵运算，但具体的数据布局、片上容量和执行方式取决于硬件。

把中间结果留在片上 ​

再看注意力。直接实现会先算出每对位置的分数，再做 softmax，最后乘 V。FlashAttention 把查询、键和值分块，处理下一块时更新行最大值、归一化因子和加权和，因此无须把整张分数矩阵写回显存。它仍计算精确注意力，主要节省的是中间矩阵的读写。

接下来要知道一次读写优化到底省了多少时间。第 6 讲先划定计时区间，再用逐行 softmax 说明多个操作怎样合成一次内核调用。
