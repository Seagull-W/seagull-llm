17 讲原始材料 ​

五份作业与对应讲次 ​

作业阅读起点目前可读
A1 基础第 1–3 讲。先分词，再搭模型，最后估算训练所需资源。RoPE 与 Transformer 块
A2 系统第 5–8 讲。先测量单卡，再研究内核和多卡通信。计时协议与理论账
A3 规模定律第 9、11 讲。观察等计算量曲线，分配模型与数据预算。课程任务
A4 数据第 13–14 讲。沿一份文档的提取、过滤与去重过程阅读。课程任务
A5 对齐第 12、15–16 讲。结合评估理解后训练目标，另有安全 RLHF 补充材料。课程任务

扩展阅读 ​

想弄清架构选择，可先读第 3 讲开头的两张架构图，再回到原始 Transformer 论文的模型结构一节，逐项对照位置编码、前馈层和归一化。如果关心两个实现为什么跑得不一样快，可以打开第 6 讲的例子，先找计时从哪一行开始、在哪一行结束，再看它测了哪个 kernel。Attention Is All You Need
