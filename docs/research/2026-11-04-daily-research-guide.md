# 每日调研导读：从后训练全景到奖励、系统与规模边界

这十六条调研从 10 月 14 日写到 11 月 2 日，题目看着分散——步骤反馈、评测口径、集群调度、蒸馏、过程奖励、框架架构——但反复撞上同一件事：后训练里没有只改一处的地方。调了采样预算，奖励的可信度读数跟着变；换了训练与推理的部署方式，梯度里就多出一项与奖励无关的漂移；把分数刷上去之后，还要回答这个分数测的是哪件事。

下面按读的顺序重排这十六条，不按发布顺序。想先看全貌的读第一节；要落到自己的训练任务，从第二节的系统账和第三节的信号账开始；第四、五节是具体机制与相邻领域，按需挑。

## 一、全景：问题先怎么摆开

### 2026-10-14 · [后训练与 agentic RL：从轨迹奖励走向步骤反馈](/research/2026-10-14-llm-post-training-agentic-rl)

站内第一篇，做法是读 arXiv 与 Hugging Face 摘要做筛选，主线是把轨迹级奖励拆到步骤上：DeltaTTG 与 ProAS 各自重新分配信号，教师指导要连可靠性一起看。它更像一份问题清单——哪些摘要值得精读、哪些结论当时还没有核验。后面几篇把这里列出的问题一条条做成了专题。

### 2026-10-15 · [大模型强化学习、后训练与 agentic RL](/research/2026-10-15-llm-post-training-agentic-rl)

同一条筛选线做了一周。单轨迹的 token 信用分配与动量被分成两件事；自蒸馏方法的摘要优势和同期对照结论不能直接相减；语言 agent 的工作转向中间动作监督与执行环境内训练。这期最该带走的是那个提醒：新方法的收益要先找到同条件的对照，再谈名次。

### 2026-10-30 · [后训练的四个争点：奖励可信、信号交接、预算分配与评测口径](/research/2026-10-30-post-training-papers-2026-10)

十二篇论文按四个争点摆开：奖励凭什么可信、蒸馏和奖励怎么交接、采样预算花在哪、涨分究竟证明了什么；组内保留分歧，不合成共识。只看一篇拿全貌就选这篇，末尾附了四个可以先做的复现实验与各自的预期结果。

## 二、训练系统的账：框架、集群与 rollout

### 2026-10-16 · [后训练 RL 框架：从训练闭环到 TRL、verl、OpenRLHF、slime 与 AReaL](/research/2026-10-16-post-training-rl-frameworks)

把「一份权重加一批题目」和一次真正的训练之间的缺口补上：数据、采样、奖励、优势、更新、权重交接怎么接起来，再沿五个真实入口读配置。同名训练器不等于同一训练目标，`GRPOTrainer` 换一种损失聚合就在改你优化的东西。

### 2026-10-31 · [主流 RL 框架的架构分歧：控制面、训练-推理耦合与环境边界](/research/2026-10-31-rl-framework-architecture)

九家框架跑的算法几乎是同一套，差别在三处工程决策：算法流程由谁表达、训练与推理怎样共享设备和交换权重、环境与 agent 的状态放在哪一侧。三处组合出框架的脾气——能扩到多大、换模型多贵、长尾生成时 GPU 空转多久。按约束选，比按排名选可靠。

### 2026-10-24 · [大模型后训练的集群调度：设备放置、通信约束与失败恢复](/research/2026-10-24-llm-post-training-cluster-scheduling)

调度的对象不是可以互换的 GPU 槽位，而是能完成通信、保持状态一致、中断后还能重组的一组资源。在线强化学习在一个作业里混着几种时间尺度——参数更新、长短不齐的轨迹生成、奖励模型的前向——于是让更多 GPU 忙起来，有时反而买到更多过时样本或更高的权重搬运成本。

### 2026-10-28 · [rollout 的算力经济学：一条训练样本值多少 token](/research/2026-10-28-rollout-compute-economics)

把一步训练的成本写成 prompt 数乘以组大小、平均长度和单 token 成本，再除以真正贡献梯度的样本比例。组内全对与全错的样本是纯浪费；异步是用样本新鲜度换吞吐；算力—效果曲线有陡段也有平台段。它给的是判断「再加采样还有没有用」的度量，不是调参口诀。

## 三、信号与分数：数据、基准、奖励模型

### 2026-10-16 · [后训练与 agent 评测：基准分数究竟证明了什么](/research/2026-10-16-post-training-rl-benchmarks)

一个基准分数省略了三件事：模型实际收到的输入、评分器实际检查的对象、训练是否已经用过同一份反馈。数学只看最终数字、代码跑有限测试、工具任务比订单终态，成功所指不同，两个分数就不能排在一条轴上。

### 2026-10-17 · [后训练强化学习数据集：来源、记录形式与对训练的影响](/research/2026-10-17-post-training-rl-datasets)

训练记录的核心是反馈从哪里来：人类比较、模型评分、步骤标签、可执行测试，分别支撑不同的训练环节。更多配对不等于更多有效问题——提示多样性、当前策略的回答分布和组内奖励差异都会改掉数据的训练价值。读它是在收数据之前先定反馈形式。

### 2026-10-18 · [强化学习中的 Reward Hacking：机制与文献整理（2022—2026）](/research/2026-10-18-rl-reward-hacking)

二十一章按机制组织的文献地图：奖励错设、过度优化、迎合、验证器、篡改、监督泛化，每章保留论文链接与实际阅读范围。它反复校正一个用法——论文里的「真值」常常只是另一个奖励模型、一组有限测试或 LLM 判定，不能顺手当成人确认过的目标。

### 2026-10-29 · [过程奖励到底有没有用：步骤级信号的可信度账](/research/2026-10-29-prm-process-reward)

过程奖励能不能用，取决于三个问题：标签从哪来、步骤按什么边界切、评测看最终答案还是看步骤判断。2023 年的正向结果建立在人工步骤标注和 Best-of-N 重排序上；自动标注把结果的噪声搬进了步骤标签；到 2026 年的对抗测试里，它会退化成流畅度检测器。

## 四、方法与规模：蒸馏、外推与训推不一致

### 2026-10-23 · [大语言模型蒸馏：从教师信号到学生自己的生成分布](/research/2026-10-23-llm-distillation)

蒸馏的三个选择是信号、目标函数和训练上下文——教师示范什么行为、学生拿什么分布去拟合、训练时接触谁生成的文本。黑盒指令与理由迁移、reverse KL、on-policy 蒸馏的差别都落在这三点上。讲机制和适用边界，不排方法名次。

### 2026-10-29 · [小模型的强化学习结论，能推到几百 B 吗](/research/2026-10-29-rl-scale-transfer)

能带到大模型上的，是「什么条件下学习信号会消失、优化会失稳、预算会被浪费」，而不是「哪个奖励函数最好」。奖励配方在 4B 与 14B 之间就可能翻转，小预算领先的配方在长训练里可能落后；万亿参数的训练动态已有证据，缺的是统一初始化、数据、评测与成本口径、并验证预测误差的联合 scaling law。

### 2026-11-02 · [Score Centering：消掉追随采样器的漂移，仍要面对采样分布偏差](/research/2026-11-02-score-centering-tim)

采样器与训练器只差一点数值，策略梯度就会多出一个与奖励无关的方向，把训练器推向采样器；下一轮权重同步又把它带回来，在线循环于是反复吸收同一份误差。Score Centering 逐前缀减掉这一项，在刻意加重的量化失配下也能稳住训练。消掉漂移之后，学习信号仍由采样器的分布决定，论文支持的是漂移修正，不是一整套训练配方。这篇技术密度最高，需要策略梯度和重要性采样的底子。

## 五、agent 侧的两个具体问题

### 2026-10-20 · [智能体沙箱：创建延迟、空闲驻留与状态恢复](/research/2026-10-20-agent-sandbox-wrong-target)

从添茶那句「工业在优化错误的目标」出发：智能体一轮循环里大部分时间在等模型，创建延迟不是墙钟瓶颈；但等待也计费，空闲驻留、内存尖峰和快照恢复会抵掉创建优化。文里的数字来自不同系统和不同实验条件，不能拼成一次测量。

### 2026-10-26 · [解读 Claude Code 团队的七层代码审查：风险分级、收敛与迁移边界](/research/2026-10-26-agent-code-review-layers)

判据从「谁读过这段代码」换成「这次改动可能怎么坏、哪一层最该拦住它」，人的阅读集中到分类器判为高风险的位置。真正值得带走的是停止条件，不是那张七层流水线图：这套流程一度不收敛，一个 CLI 的 PR 一夜跑了五十多轮，靠四条约束才把轮数与通过率压回可用的区间。
