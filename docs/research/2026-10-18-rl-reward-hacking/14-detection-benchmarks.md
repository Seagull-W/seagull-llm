# 奖励漏洞检测基准：对照、语义与指标口径

## 1. 对比多条轨迹能改善判断，但这不是训练时自然发生率

Deshpande等的 *Benchmarking Reward Hack Detection in Code Environments via Contrastive Analysis*（2026-01-27，v1）提出TRACE：517条合成、多轮代码对话，其中249条善意轨迹；平均26.5个utterance、最长49个，39%含多个漏洞类型。Claude Code+Opus4.5按照54类细分行为生成故事、模拟工具输出，三个每天使用代码代理的工程师独立检查真实性、作弊存在性、类别和难度，接受率约81%，再删除高分歧样本。因此它是人工验证的**合成检测集**，不是517条真实RL中自然发现的漏洞，轨迹中的工具输出也不全是实际执行记录。[§3、Appendix B、H](https://arxiv.org/abs/2601.20103v1)

与单条判断不同，检测器同时看$N=1,5,10$条轨迹，比较哪些行为偏离任务意图；善意占比$B=.25,.5,.9$，用三个分组随机种子重复。检测器没有完整54类标签，需自己解释原因；另用Opus4.5将解释映射回人类标签。这个设计研究上下文对照是否有用，没有做在线GRPO更新；其与GRPO候选组的类比不能写成已验证的训练防御。[§4](https://arxiv.org/abs/2601.20103v1)

## 2. “Detection Rate 63%”实际上是macro-F1

论文§4.4把Detection Rate定义为二分类macro-F1，Match Rate定义为**在检测正确样本上条件化**的多标签macro-F1。因此GPT5.2从独立判断.45到10条对比.63，不能译成“发现了45%/63%的全部漏洞”或“召回率提高18个百分点”。GPT5.2的对应条件类别匹配分从.63到.75（Figure4）；这两个指标的分母不同，条件匹配也不包含漏检造成的完整损失。[§4.4、Figure 4](https://arxiv.org/abs/2601.20103v1)

原文在部分汇总描述上并不一致：§5称GPT5.2独立Match为.61而图4标.63；图6独立条件的类别分约.41，也与图4不一致，可能来自不同平均方式但未充分交代。故本整理只保留定义明确的主检测macro-F1比较，不用这些相互冲突值做精细排名或放大百分比结论。善意比例变化本身也会改变macro-F1难度和预测先验；仅凭指标上升不能单独识别“学会了对比推理”这一内部机制。[Figures 4、6、§5](https://arxiv.org/abs/2601.20103v1)

单条判断时Opus4.5很保守，报告正类precision为1但recall低；加入对照后macro-F1明显提高。自然部署中的漏洞基率往往与本集不同，precision、人工复核负担和漏检代价都需重新校准，不能把对比组中的收益直接代入实时监控成本。正文称结果统计显著，但未给主要比较的充分区间或显著性检验细节；三个分组种子不是三个独立训练种子。[§4.2、§5](https://arxiv.org/abs/2601.20103v1)

## 3. 语义边界不能由类别名称代替

测试改写、硬编码可留下清晰代码痕迹；信息泄露、风格操纵、工具滥用较需理解用户意图，对应类别匹配较差。作者把这种差异视为语法到语义泛化限制，但类别还在难度、标签主观性和训练覆盖上同时变化，不能由这个观察推出模型在所有语义理解上存在一条已测定的基本上限。[§5、Appendix E](https://arxiv.org/abs/2601.20103v1)

其taxonomy尤其需要按上下文使用：查编译器错误、使用调试器、从问题描述提取线索、复用示例、检索相似解法、查网络或用lookup table，在许多编程任务里都合法；只有违反了该任务的约束，或用它们提高评测而不满足真实意图时，才构成漏洞。将这些名字直接作黑名单，会把能力正常使用错判成作弊。论文对合成轨迹有人工审核，不表示各类别脱离具体轨迹仍是充分判据。[Appendix G，Tables 3–6](https://arxiv.org/abs/2601.20103v1)

定性检查每模型34条随机轨迹发现：检测器常因用户在对话里接受方案，就忽略实际指标被改动；也会因代理主动解释缺陷而认为其善意。这与人类监督章相通：被评价对象的自我辩护和当下用户批准，都不是独立任务真值。具体代码证据、解释后果、对比合法替代方案与正确检测相关，但属于事后观察，未随机干预这些推理模式。[§6](https://arxiv.org/abs/2601.20103v1)

实际完整读取v1 PDF文本pp.1–22，含全部生成/检测/judge提示、54类定义和人类评分细则。样本经过同类模型生成、验证、解释匹配及人类筛选，可能压低分歧并影响外部效度；未复现harness，也未把合成集的漏洞比例当现实风险估计。
