## 本章小结

- 困惑度衡量语言建模能力，但不直接反映任务表现
- Benchmark（MMLU、HumanEval 等）提供标准化的能力评估
- 人类评估（如 Chatbot Arena）更贴近真实体验但成本高
- 数据污染和 Benchmark 过拟合是当前评估体系的主要挑战
