## 本章小结

- 上下文窗口是模型单次推理能处理的最大 token 数
- 限制来源于注意力机制的 O(n²) 计算复杂度和 KV Cache 的显存占用
- 位置编码为排列不变的注意力机制注入位置信息
- RoPE 是当前主流的相对位置编码方案
