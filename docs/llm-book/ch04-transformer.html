本章小结 ​

  • Transformer 摒弃了循环结构，完全基于注意力机制
  • GPT 类大模型采用仅解码器架构，通过自回归方式生成文本
  • 数据流：Token → 嵌入 → 解码器层堆叠 → softmax → 概率分布
  • 层数、隐藏维度、注意力头数是决定模型规模的核心超参数
