大语言模型智能体强化学习全景：综述

摘要

智能体强化学习（Agentic RL）的兴起标志着一种范式转变：与应用于大语言模型的传统强化学习（LLM RL）相比，它将大语言模型从被动的序列生成器重新定位为置身复杂动态世界、能够自主决策的智能体。本综述通过对比 LLM RL 中退化的单步马尔可夫决策过程（MDP）与界定 Agentic RL 的时间延展的部分可观测马尔可夫决策过程（POMDP），对这一概念转变进行形式化。在此基础上，我们提出一个全面的双重分类体系：一条主线围绕规划、工具使用、记忆、推理、自我改进和感知等核心智能体能力展开，另一条主线按照不同任务领域中的应用组织。本文的核心论点是，强化学习是将这些能力从静态的启发式模块转化为自适应、稳健的智能体行为的关键机制。为支持并推动后续研究，我们将开源环境、基准和框架汇集为一份实用资料目录。通过综合五百余项近期研究，本综述勾勒出这一快速发展领域的轮廓，并指出将影响可扩展通用人工智能体发展的机遇与挑战。
