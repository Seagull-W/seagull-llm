本综述梳理了智能体强化学习（Agentic RL）的兴起。这一范式将 LLM 从被动文本生成器提升为置身复杂动态世界的自主决策智能体。我们首先形式化这一概念转变，将表征 Agentic RL 的时间延展、部分可观测马尔可夫决策过程（POMDP），与传统 LLM 强化学习的单步决策过程区分。在此基础上，构建全面的双重分类体系来系统描绘该领域：一条主线围绕核心智能体能力，包括规划、工具使用、记忆、推理、自我改进和感知等；另一条主线围绕这些能力在多样任务领域中的应用。贯穿全文的核心论点是，RL 为将这些能力从静态启发式模块转化为自适应、稳健的智能体行为提供了关键机制。我们还整理开源环境、基准和框架，为这一蓬勃发展领域的后续研究提供实用资料，支持并加速研究推进。
