1. 对象与证据版本 ​

INTELLECT-3 是从 GLM-4.5-Air-Base 后训练的 106B-A12B MoE。团队于 2025-11-26 发布，2025-12-18 提交报告。研究对象包括模型训练、prime-rl、verifiers/环境生态和集群运维。作者博客、模型卡、报告 v1

本轮已读取报告全文、模型卡以及当前 prime-rl 文档并保存快照。报告对应当年实验；当前 main 文档是另一个版本证据，原 run 的精确仓库 SHA 与 resolved config 尚未核验。

2. 数据、环境与训练阶段 ​

实际路径为 Base → 通用推理 SFT → Agent SFT → 混合环境 RL。SFT 来源表列出 Nemotron 与 AM 蒸馏数据，以及工具/软件工程和环境生成轨迹；RL 覆盖数学、代码、科学、逻辑、研究与软件工程。环境统一连接 verifiers，代码/SWE 执行依赖沙箱；报告说明 sandbox 失败会屏蔽相应 completion。报告 §3.1–3.3

阶段 报告中的训练参数
通用推理 SFT 1 epoch、context 65k、约 33M tokens/step；Muon LR 5e-5、weight decay 0.01、300-step warmup 从 1e-8 开始；FSDP64×DP replicate8
Agent SFT 从前阶段 checkpoint 继续；2 epochs、context 98k、CP；Muon LR 5e-8、800 steps 内线性衰减
RL 256 prompts×16 rollouts、context 65,536；Muon LR 1e-6、最大 off-policy steps 8

出处：报告 §3.2–3.3。这些是不同阶段的参数，不能将 SFT 的 CP/context 或 LR 拼进 RL 配方。独立偏好优化阶段本轮未核验。

环境发布为可以固定版本的 Python 模块，使 task、评分与评测实现能够单独更新。需要同时固定环境包、数据 split、工具定义和 sandbox 镜像。作者博客 当前框架关于 prompt/completion、messages 和 loss mask 的接口说明见 training，其默认值不能直接套到 2025 年实验。

3. 算法、更新与 rollout ​

报告给出 RL batch 为 256 prompts×16 rollouts，context 65,536，最大 off-policy steps 为 8，Muon LR 为 1e-6。算法采用 IcePop 的 token 重要性比值双侧 mask（0.5–5）和组内去均值优势；极低 token ratio 还会触发轨迹屏蔽。在线难度筛选用于维持学习信号。报告 §3.3

框架由 CPU orchestrator、FSDP2 trainer 与 vLLM inference 分工：环境生成/评分，orchestrator 构建批次，trainer 更新模型，推理服务接收权重。持续采样和在途更新允许轨迹跨权重版本，必须记录生成概率与版本滞后。当前 overview、algorithms

6. 失败尝试、修复与恢复 ​

报告记录了三类实际反馈：异步 activation offload 的 CUDA-stream 内存泄漏，改用同步实现；长上下文 CP 尝试出现精度问题而未用于生产；高 off-policy 消融中 GSPO 出现 reward/指标崩塌。这些是作者实验反馈，不是本轮集群复测结论。报告 §2.1.6/§3.3

原始泄漏栈、失败 batch、修复 commit 和各次重启状态未取得。当前框架的 checkpoint、恢复和日志用法可查 training、advanced。读取当前恢复说明只能确认功能接口；还不能证明原 run 恢复了 queue、RNG、environment 与所有在途轨迹。
