Count Counts：用访问频率引导推理探索 ​

一道题有两条解法。模型已经熟悉第一条，偶尔才会试到第二条。如果两条都能答对，结果奖励给它们相同的分数。MERCI 额外估计一条回答经过了多少少见的推理状态，让答对且较少尝试的路线在下一次更新中获得更大的权重。

结果奖励留下的探索问题 ​

在数学推理训练中，模型生成一整条回答，验证器才给出最终得分。一条熟悉的路线只要经常答对，就能反复获得正反馈。另一条路线可能要连续走对好几步才有机会得到同样的反馈。提高生成分布的熵可以让下一步有更多选项，但换个措辞也能提高词元（token）的多样性，解题思路可能依旧相同。论文 §1

MERCI 采用一个可计算的判断依据：若一段推理经过的状态在训练中很少被访问，就给它一定的探索激励。困难在于，几乎每个完整文本前缀都独一无二，逐字匹配很难积累有意义的计数。作者沿用 Coin Flipping Network（CFN），在隐藏表示上学习访问频率的代理量，再决定这份新颖性应当在多大程度上影响策略更新。§2、§3.2

抛硬币如何估计访问频率 ​

设同一状态出现了 n 次。每次访问都重新抛 d 枚独立的公平硬币，把正反面编码为 +1 和 −1，得到一个随机标签向量。CFN 以该状态的隐藏表示 h 为输入，通过平方损失拟合历次标签。论文取 d = 20。§2，式 (1)–(2) · §5.1

对于相同的输入，平方损失最小的预测是这些标签的平均值。只访问一次时，每个坐标都是 +1 或 −1。访问次数多了，同一坐标上出现的正负号会彼此抵消。平均向量缩小的速度，恰好提供了频率信息。

左式是对随机标签取期望得到的统计关系，右式是实际用网络输出计算的逆伪计数。理想情况下，访问一次时归一化平方模长为 1，访问 100 次时其期望为 0.01。对真实文本，前缀很少完全重复，可用信号依赖网络对相近表示的泛化。较大的 u 表示 CFN 将该位置判断为较少访问。

探索项如何保留任务优势的符号 ​

同一道题的一组回答会得到一组分数 Bᵢ。作者先用组内均值和标准差将分数标准化，只取正的部分。于是低于平均新颖性的回答获得零探索增量。

一次 MERCI 训练迭代 ​

训练前，作者用初始策略生成的回答预训练 CFN。进入强化学习阶段后，每轮更新的顺序决定了“少见”相对于哪一刻的访问历史。§5.2 · 算法 1

  1. 策略为同一问题采样多条回答，用数学答案或 SQL 执行结果计算外部奖励及原始组内优势。
  2. 用当前 CFN 给各条回答逐位置评分。筛选位置、按完整长度聚合，得到每条回答的探索分数。
  3. 在同题组内标准化探索分数，截去负值，并按原优势的绝对值限制增量，得到 GRPO 或 DAPO 使用的新优势。
  4. 用新优势更新策略。同时为这批访问重新采样随机标签，更新 CFN。先给轨迹评分，再让 CFN 吸收这批访问，下一轮的评分才会反映这段新历史。

方法的适用边界 ​

访问频率的解释范围。CFN 接受的是随机标签监督。它给出的高分说明某段表示在当前训练历史中显得少见，无法单独判定推理是否正确，也无法直接读出该类题目在预训练语料中的占比。§3.2

探索激励依赖任务信号。稀有但错误的路线能获得多大增量，由原优势决定。特别是整组原优势都为零时，保护任务方向的限幅也消除了探索增量。这是式 (8) 的直接推论。式 (8)
